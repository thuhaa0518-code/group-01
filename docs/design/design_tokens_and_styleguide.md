# 🎨 Design Tokens & Styleguide (Bảng Mã Màu & Typography)

---

## 1. Bảng Màu Hệ Thống (Color Tokens Palette)

### 1.1 Thương Hiệu & Tương Tác (Primary & Interactive)
- **Primary Base:** `#155EEF` (`primary-600`) - Sử dụng cho nút bấm chính, liên kết kích hoạt.
- **Primary Surface:** `#EFF8FF` (`primary-50`) - Nền ô được chọn, highlight trong bảng.
- **Primary Border:** `#B2DDFF` (`primary-200`) - Đường viền thành phần được chú ý.

### 1.2 Trạng Thái & Thông Báo (Status Tones)
- **Success (Thành công / Approved):** Text `#079455`, Nền `#ECFDF3`, Border `#ABE5C6`.
- **Warning (Cảnh báo / Review):** Text `#DC6803`, Nền `#FFFAEB`, Border `#FEDF89`.
- **Danger (Lỗi / Rejected):** Text `#D92D20`, Nền `#FEF3F2`, Border `#FECDCA`.
- **Info (Thông tin / AI Suggestion):** Text `#175CD3`, Nền `#EFF8FF`, Border `#B2DDFF`.

## 2. Quy Chuẩn Typography (Kiểu Chữ)

- **Font Family:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif`.
- **Font Mono (Mã đơn / ID):** `ui-monospace`, `SFMono-Regular`, `Menlo`, `Monaco`, `monospace`.

| Style Name | Size / Line Height | Weight | Usage |
| :--- | :--- | :--- | :--- |
| **Heading XL** | 24px / 32px | Bold (700) | Tiêu đề chính trang web |
| **Heading LG** | 20px / 28px | Semibold (600) | Tiêu đề Section, tên đơn PR |
| **Heading MD** | 16px / 24px | Semibold (600) | Card header, tên Modal |
| **Body Regular** | 14px / 20px | Normal (400) | Văn bản mô tả, nội dung bảng |
| **Caption / Tag** | 12px / 16px | Medium (500) | Tag trạng thái, nhãn phụ |
